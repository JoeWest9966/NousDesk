# 资源页的词表（先认字，再动手）

资源页（`crates/nousdesk/src/resources.rs`）里这几样东西**不是同一个层级**，
混着叫就会做出「点一下筛选器把整列换掉」这种错（2026-11-23 真机被指出过两次）。
排错、加功能、写文案之前先看这一页。

## 一、空间：列

| 词 | 是什么 | 宽窗（≥ 约 1000px） | 窄窗（约 980px） |
| --- | --- | --- | --- |
| 图标条 | 最左边那条（会话 / 资源 / 模板 / 数据库 / 设置） | 在 | 在 |
| **资源列** | 装资源页内容的那一列 | 拆成**左树**（248）**+ 列表**（300）两列 | 合成一列（300），树与列表是这一列的两层 |
| 详情列 | 右边看单条详情的那一列 | 在 | 在（**窄窗也不许被吃掉**） |

要点：

- 「资源列」指**这一列本身**，不是最左边的图标条，也不是「详情」。
- 窄窗里资源列有**两层**：`条目层`（筛选器 + 列表）与 `类别层`（只有类别）。
  这是 `ResCol::{Items, Tree}`，位置跟模板页的 `NarrowCol` 同一个套路。

## 二、东西：筛选器 vs 类别

### 筛选器（filter）

「列表里显示哪一批」的开关。**改的是列表内容，不改变你在哪一层，也不许换列。**
段只有三个值（`Section::{Skills, Prompts, Extensions}`），各占一个槽位（0/1/2），
类别筛选与搜索词按槽位各存一份 —— 切段时词和类别都还在（`Section::slot()` 是唯一下标源）。

- **段**：`技能` / `提示词` / `扩展` —— 资源页的三个段（`Section`），平铺。

2026-11-24 之前还有一层「内容」段（把技能和提示词裹在一起、再挂一个子开关）。
那层**不装任何东西、只多一次点击**，已删：三个段现在并列，`Section` 里只有三个值，
没有 `Content` 这个类型了。

所以 `技能`、`提示词`、`扩展` 三个都是**筛选器**，不是层级节点。

- 宽窗：它们挂在左树顶上（三个段按钮），因为那一列本来就是「树的列」。
- 窄窗：它们**留在列表头顶**（同一行三个 pill），**不搬进树**。
  搬进树它们就成了层级，点一下等于把这一列换掉 —— 用户看到的是「点『技能』直接切到技能详情」，
  这是错的。

### 类别（category）

**类别是内容的分类**，也就是私库 / 清单里那一行字符串（`items[].category`、`SKILL.md`
的 `category`）。树里显示的就是类别，点类别才算「导航」：窄窗下点类别 → 资源列从类别层
回到条目层，并筛出这一类的条目。

两类要分清：

| 词 | 例子 | 说明 |
| --- | --- | --- |
| 真实类别 | `Basics`、`写作`、`效率` | 仓里 / 词表里真有的类别（`GET /v1/extensions/categories`） |
| **虚拟类别** | `未分类`、`隐藏（模型看不见）`、`默认` | 不是仓里真有的类别，是「没挂类别的那些」「模型看不见的那些」这类**内容的类别**汇总 |

状态桶（`启用中` / `加载失败` / `待重写` / `内置` / `变体` / `已归档`）在扩展段里长在
类别树的位置上，但它们仍然是**筛选**（按档位 / 状态筛）。它们跟虚拟类别一样，点了是
「筛出这一批」，不是「进到某一层」。

### 其它

- **条目**：列表里的一行（一条技能 / 提示词 / 扩展）。窄窗的 `条目层` 就是列表这一层。
- **垃圾站**：**另一页**（`View::Trash`），不是筛选。卸载过的东西不在清单里，混进类别树会被
  当成「另一个类别」。空着也要显示那行 —— 它是入口。
- **类别词表**：`View::Categories`，管「有哪些类别」，跟某条扩展挂哪个类别（`View::Category`）是两回事。
- **段工具**：扩展段列表头那颗 `⋯`（`res-ext-more`）。里面是 `重载` / `类别词表…` /
  `垃圾站 N`（垃圾站空着不出现，树里那行一直有）。技能、提示词段没有段工具。

## 三、三条判据（写代码时照着判）

1. **筛选器只换列表内容**：`resource_section`，绝不动 `narrow_col`。
2. **只有类别能改层**：窄窗里 `cat_row`（`res-cat-*`）点下去才 `narrow_col = Items`。
3. **层只由两颗 chip 改**：`☰ 类别`（`res-open-tree`）钻上去，`‹ 条目`（`res-back-items`）退回来。

违反第 1 条的现象就是「点筛选器整列被换掉」；违反第 2 条的现象是「点了没反应」。
