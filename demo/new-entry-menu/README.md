# 左栏 ＋ 新建菜单：多出「从模板起」「复制这条会话」

双击 `preview.html` 就能看（单文件，数据内嵌，不连引擎、不联网）。

现在左栏头部那颗 `＋` 只有一个「New Manual」。这一轮要给它加两条入口，顺带把快捷键挂上，
先在这里挑手感，定了再写 Rust。

## 要你拍板的三件事

1. **选哪个方案**（顶部三个按钮切着看，深色皮也能切）：

   | 方案 | 长什么样 | 代价 |
   | --- | --- | --- |
   | **A 平铺** | 三行一条直线 + 右边挂快捷键 | 「起新的」和「从这条派生」混在一起；将来加第四条没地方 |
   | **B 分组** | `新会话`（空白 / 从模板起）· `从当前这条`（复制设置 / 连对话一起复制） | 菜单高一点（两行组标题） |
   | **C 两级** | `＋` 展开一行「新会话…」，往右飞出二级 | 两次点击；窄列里飞出会盖住聊天区顶上一角 |

2. **「复制这条会话」复制什么**（只有 B 把这个问题摆出来了）：
   - **只复制设置**：模型 / cwd / 模板 / skills，对话从零开始。← 我倾向这个
   - **连对话一起复制**：新会话里就能看到那 12 条历史，等于「分支但不 fork 引擎那边」
   两个都留也行，但菜单里出现两个「复制」本身就是个解释成本。

3. **快捷键**（菜单里必须写出来，不写等于没有）：
   `Ctrl+N` 空白 · `Ctrl+Shift+N` 从模板起 · `Ctrl+D` 复制这条。
   嫌 `Ctrl+D` 撞别的（有的应用是书签 / 退出），换成 `Ctrl+Shift+D` 也行 —— 一句话的事。

## 已经按「浮层四条」做了的

- 开启它的按钮就是 `＋` 本身，开着时**按钮自己亮着**（toggle），再点一次关。
- 三条出口：点外面 / `Esc` / 再点 `＋`。
- 菜单项 34px 高（≥24px 命中区）、有 hover。没选中会话时「复制」整行灰掉并写「先选一条」；
  真点下去会给一条 `先选一条会话` 的提示，不是「点了没反应」。
- 「从模板起」不是再弹一层浮层，而是**同一块地方换成模板列表**（省得两层叠着、也省得算位置）。

## 写 Rust 大概要动的地方

- `app.rs` 的 `render_new_chat_button` / 现在那个只含 New Manual 的极简下拉：菜单项变多，
  分组要用 `DropdownMenu` 的 group（已经在用 gpui-kit 的）。
- 「从模板起」：`/v1/presets/<段>` 已经在拉了（Template 页在用），拉一次缓存住；
  选中后走 New Manual 那条 `CreateSession`，把 `preset` 带上。
- 「复制这条会话」：把当前会话的 `model` / `cwd` / `preset` / `skills` / `extensions` 抄进
  `CreateSession`，**不带 entries**。这需要 `wire.md` 先确认哪些字段 `POST /v1/sessions` 能吃。
- 快捷键：`intercept_keystrokes` 里加三条（跟现在 Ctrl+S / Ctrl+K 同一处，注意别在输入框聚焦时抢）。
