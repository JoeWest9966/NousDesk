# demo · 左列行内的第二行写什么（149 条同名会话怎么扫）

**只看这个文件**（单文件，无外链、无构建）：双击 `/opt/NousDesk/demo/list-row-info/preview.html`。
左上角切换五个方案，可以开深色皮、「固定显示 hover 态」（方便看 hover 长什么样）。

## 要解决的问题

不是「想加东西」，是**这一列现在扫不动**。拿引擎真实数据量的（`/v1/sessions`，149 条主线）：

| 事实 | 数字 | 直接后果 |
| --- | --- | --- |
| 有 `last.text`（能做预览）的 | **7 / 149** | 142 行第二行是空的，`min_h(56)` 硬撑成两行的高度 |
| 有 `updatedAt` 的 | **2 / 149** | 147 行右半边没有时间，看起来像渲染缺了一块 |
| 名字重复的 | **36 条** | `对话 371` / `对话 377` / `scratch 11-13 19:16` 一组一堆 |
| `model` 是同一个值的 | 大多数 | `deepseek-v4-flash`；`cwd` 也大多都是 `map/qrd3wh` |
| 行上有没有 hover 反馈 | **没有** | 鼠标划过 149 行毫无变化（`.when(selected, bg)` 之外没有 `hover`） |

还查了一件更要紧的事：**这 142 条空行是真的空**（`/v1/sessions/389/entries` 返回 `{"items":[]}`），
不是 `last` 字段漏了。所以「补预览」这条路对这些行根本不存在 —— 能给的只有元信息。

## 五个方案（左上角切换）

| | 第二行写什么 | 行高 | 右侧 | hover |
| --- | --- | --- | --- | --- |
| **1 基线** | 只写预览，没有就空着（**现在线上的样子**） | 固定 56 | 有时间才画 | 无 |
| **2 密度优先** | 只写预览；空会话不编内容 | 随内容 **56 / 40** | 有时间才画 | 淡底 |
| **3 去重兜底** | 预览 → 空会话用「模板 · 机器 · 模型 · cwd」，**跟上一行完全一样就省略** | 随内容 56 / 40 | 有时间才画 | 淡底 |
| **4 信息栈** | 预览 → 空会话全摆上：`#id · 模板 · 机器 · 模型 · cwd`，不去重 | 随内容 56 / 40 | 时间 + 机器角标 | 淡底 + 左 2px 条 |
| **5 只留编号** | 预览 → 空会话只写 `#id` | 随内容 56 / 40 | 有时间才画 | 淡底 |

**方案 3 为什么要有「去重」**：`model` + `cwd` 对绝大多数行是同一个值，无脑兜底等于 149 行都写同一句
`deepseek-v4-flash · map/qrd3wh` —— 比空着更糟，因为它每行都在喊同一件事。所以只有「变了」才画
（跟 `git log --oneline` 去重一个道理）。

**方案 4 为什么值 一看**：真正唯一的字段其实只有 `#id`（名字里的 `#536` 是作者自己誊上去的）。
`model` / `cwd` / `template` 在 149 条里翻来覆去就那几个值。

**方案 5 是 4 的减法**：既然只有 `#id` 有信息量，就只留它。最短、且永不重复。

## 我倾向哪个

**2 + 5 的组合**，理由是两件事分开做：

- **密度**（2）：没内容就不占地方。一屏从 11 行变 15 行，149 条少滚 1/4。
- **编号**（5）：空会话那行给个 `#418`，既区别于邻居，又正好是你能对着 `/v1/sessions` 查的那个数。
  跟名字里已经写着 `#536` 的那些行也对得上。

3 和 4 留在这里是为了让你看见「无脑兜底会长什么样」—— 看着就知道为什么不能那么干。

## 选完要改的地方

`crates/nousdesk/src/app.rs`：

- `session_row()`：`.min_h(t().d(56.))` → 有第二行才 56，没有用 40（`when(has_second_line, …)`）
- `session_row()`：第二行那个 `else` 分支里加 `#id`（现在是 `hl_line(&preview, …)` 单独一个元素）
- `session_row()`：`.when(selected, bg)` 旁边补一行 `.hover(|s| s.bg(rgb(t().p.sidebar_hover)))`（方案 2–5 都要）。
  调色板里没有专门的「行 hover」，先复用 `sidebar_hover`（纸皮 `#f5f5f3`，比选中色 `#ececea` 浅一档）；
  要是你觉得行 hover 跟图标条应该分开，就加一个 `row_hover`，五套皮各补一个值
- 右侧时间：`when_text(s.updated_at)` 已经是 `Option`，没有就不画 —— 这条不用改
