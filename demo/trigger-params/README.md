# 触发器 · 参数声明编辑器（demo）

向导第 2 步现在是「每行一个参数：`name|type|label|required|options`」，而且样例是写死的。
三套方案把这一步换成真能编辑的，共用一份数据、底下实时生成 `params`。

- `index.html` + `fonts/` —— 改这份，`python3 build-preview.py` 生成单文件 `preview.html`
- `preview.html` —— 发出去的那份（字体内嵌，双击就开）；`#a` `#b` `#c` 直接落在某个方案

| 方案 | 想干什么 | 代价 |
| --- | --- | --- |
| A · 表格行 | 参数少时一眼看完：名字 / 类型 / 必填 / 标签同一行，说明和默认值折起来 | 参数一多就得来回展开 |
| B · 卡片堆叠 | 字段全摆在外面，填的时候不用展开任何东西 | 占地方；大部分参数用不到 help / 默认值 |
| C · 主从 | 跟触发器页其他地方一个路数：左边清单，右边选中那一个的全部字段 | 参数只有一两个时，右边一片空白 |

真实数据参考：`dep-alert` 0 个参数，`single-shot` 1 个（`epoch`）。所以日常态是「很少」。
