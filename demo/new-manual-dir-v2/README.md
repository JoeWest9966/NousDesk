# New Manual · 工作目录 · 8 套（终极形态）

`index.html` 直接双击打开。8 套两列并排，弹层宽 460 / 520 / 620 三种，数据全来自 `/v1/fs/dirs` 真实返回。

## 上一版的错误前提

上一版四套都画成「map 是根」，错的。看完内核源码（`qrd3wh/server.js:2040`）：

```js
real = await realpath(path.resolve(expandHome(p)))   // 展开 ~，任意绝对路径
for (entry of await readdir(real)) { … }             // 只跳隐藏目录和 node_modules，最多 500 条
return { path: real, parent: …, dirs }
```

- **没有白名单**：`?path=/` 返回 18 项、`?path=/etc` 142 项、`?path=/root` 也行
- **`~` 会展开**（`expandHome`）
- **`?machine=` 能列远端机器**（`browseRemoteDirs`）—— 我们 UI 一直没用，切机器后拿的还是本机列表
- `resolveCwd` 同样只校验「存在且是目录」

所以：**路径的根是 `/`，起点是 map；机器才是路径的第一段。**

## 八套

| # | 方案 | 一句话 |
| --- | --- | --- |
| 01 | 单行面包屑 · 首字符消歧 | 上一版的 03 + 能爬到 `/`。`/` 或 `~` 开头 = 路径，别的 = 搜索 |
| 02 | 双行 · 输入框常驻 + 面包屑 | 两个控件都不藏，没有模式切换 |
| 03 | 命令行 · 一条 `›` | 纯键盘一行，最快也最劝退 |
| 04 | 机器是路径的第一段 | `j1900 : /opt/…/map`，换机器 = 换根 |
| 05 | 分组 · 最近 + 子目录 | 天天用的目录永远在第一屏 |
| 06 | 树形 · 点箭头展开、点名字才跳 | 结构可见，但两个热点挤在 12px |
| 07 | 双栏 · 左树右列表（620 宽） | 「我在哪」和「这层有什么」同时可见 |
| 08 | **终极 · 命令面板（620 宽，带预览）** | `ncm` 模糊匹配出 `/opt/Nous/content/new1/map`，右边常驻预览 |

## 不成套的地方（页面上都写了）

- **01** 一聚焦整行变路径，面包屑会"消失" → 靠「初始内容 = 完整当前路径」兜
- **02** 两行都在说「你在哪」，省不下来的 70px 正好一个子目录
- **03** 把「点」废掉了，面包屑不能点了
- **04** 远端列目录要 SSH，慢的那台会卡
- **05** 「最近」要存状态，而且新目录排不上号
- **06** 箭头和名字两个热点压在 12px 上，误点率高
- **07** 620 宽意味着窄档（右格 < 780）直接不存在
- **08** 三档断点里只有 ≥780 放得下；模糊排序在内核，我们只能把候选摆出来

## 我的定稿建议

不是选一套，是**一套在三种宽度下的三副面孔**：

```
≥780 ：01 的骨架 + 04 的机器段 + 05 的最近组 + 08 的预览栏（弹层 620 宽）
620–780 ：01 的骨架 + 04 的机器段 + 05 的最近组，去掉预览（弹层 460 宽）
<620 ：01 的单列，机器段退化成弹层标题下的一个 chip，面包屑折叠成 /…/map
```

**03 / 06 不做**：一个把鼠标废掉，一个把两个热点压得太近。
