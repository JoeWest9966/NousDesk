New Manual · 工作目录 · 8 套

上一版的四套都建立在「map 是根」这个错误前提上。真实情况是：内核能列这台机器上的任意路径 —— ?path=/ 直接返回 18 项，~ 也能展开，只要目录真实存在就能当 cwd； 而且 ?machine= 能列远端机器的目录——这条我们 UI 完全没用。 所以这一版把「路径的根是 /，起点是 map」和「机器是路径的第一段」两件事都摊开， 再和上一版选中的「单行 + 折叠面包屑」拼在一起，做到能到的尽头。

GET /v1/fs/dirs?path=/

boot dev etc home media …
GET /v1/fs/dirs?path=/etc
142 项 · 无白名单
内核只跳隐藏目录和 node_modules
GET /v1/fs/dirs?machine=j1900
远端机器也能列
我们 UI 一直没吃这个参数

01

单行面包屑 · 首字符消歧

上一版的 03 加上「能爬到 /」。首段是 /，一直可点； 打 / 或 ~ 开头 = 路径，打别的 = 搜索。下面这条已经是输入态。

好处：一条规则消掉歧义，还是 shell 的老约定，不用解释。 代价：一聚焦就整行变路径，面包屑会"消失"——靠「初始内容 = 完整当前路径」来兜，光标在末尾。

02

双行 · 输入框常驻 + 面包屑

两个控件都在，谁也不藏。输入框空着时面包屑就是导航，输入框一有字下面变结果。 下面这条是搜索态（打了 prompts）。

好处：没有模式切换，两个入口永远看得见，谁也不用猜。 代价：两行都在说「你在哪」——省不下来的 70px 正好是一个子目录。

03

命令行 · 一条 › 提示符

没有面包屑、没有标题行，只有一条命令输入 + 结果。纯键盘、纯一行。 打路径就跳，打名字就找，. 开头是操作。

好处：最快的形态，460 宽里塞进最多信息，而且完全不用鼠标。 代价：对不用键盘的人是堵墙——面包屑能"点"这件事在这里没有了，只能打字。

04

机器是路径的第一段

上一个问题里最该补的一条：?machine= 能列远端机器。 那机器就不该是弹层外面那颗 pill，而是路径的第一段——换机器 = 换根，跟换盘一样。

好处：「哪台机器上的哪个目录」变成一句话，不再是两个控件拼起来的猜测。 远端目录直接出现在同一个浏览器里，不用先切 pill 再开弹层。 代价：机器多一个段，路径就长一段；而且远端列目录要 SSH，慢的那台会卡。

05

分组 · 最近 + 子目录

列表分三组：最近用过（跨目录，直接跳）、当前目录下、上一级。 组头极轻，只有一行 mono 小字加一条细线。

好处：省掉一整串点击——天天用的那几个目录永远在第一屏。 代价："最近"要存状态（本地还是引擎？），而且新目录永远排不上号，会让人以为没列全。

06

树形 · 点箭头展开、点名字才跳

箭头和名字分开：点箭头 = 原地展开（看结构），点名字 = 进去（换内容）。 一层一层点得太累的时候，能一眼看完兄弟目录。

好处：结构可见。知道"map 旁边还有什么"，不用来回上下。 代价：两级交互压在 12px 的两个热点上，误点率高；宽度也不够，深一层就全挤。

07

双栏 · 左树右列表（620 宽）

弹层加宽到 620：左边是可折叠的树（整个 / 往下三层）， 右边是当前选中目录的子目录。树给结构，列表给操作。

好处：「我在哪」和「这层有什么」同时可见，深路径不用来回爬。 代价：弹层要加宽到 620——窄档（右格 < 780）时这个形态直接不存在，得退回 01。

08

终极 · 命令面板（620 宽，带预览）

把所有东西收进一个输入框：打 ncm 就模糊匹配出 /opt/Nous/content/new1/map（首字母缩写）， 打 / 开头就是路径，右边常驻一栏告诉你这个目录是什么（哪台机器、几个会话、是不是 git 仓库、空不空）。 结果行左侧是路径，右侧是「哪台机器 · 几个会话」——那是选目录时真正要在乎的两件事。

好处：一次输入决定一切。不用先想「我在哪一层」，直接从任意位置到任意位置； 预览把「选错了会怎样」提前说清楚（这台机器上已经有 3 个会话跑在这里）。 代价：这是这个盘面里唯一一个"要学"的控件——三档断点里只有 ≥780 放得下； 而且模糊匹配的排序在内核，我们只能把候选摆出来，排得对不对不由我们定。

这几套不是并列的，是一条台阶

01 是保底：单行、任何宽度都能活、规则一句话说完。
04 是必须补的：机器是路径的第一段，不然 ?machine= 永远用不上。
05 是纯赚的加速度：最近用过的目录，成本最低收益最高。
08 是尽头：模糊匹配 + 预览 + 一切路径。
03 / 06 我不建议做 —— 一个把「点」废掉，一个把两个热点压在 12px 上。

真要我定：01 的骨架 + 04 的机器段 + 05 的最近组 + 08 的预览栏， 弹层在 ≥780 用 620 宽（带预览），620–780 用 460（去预览），<620 退化成 01 的单列。 这就是"终极形态"——不是选一套，是这套在三种宽度下的三副面孔。
