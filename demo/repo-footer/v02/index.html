关于头像（这条先说清楚）

引擎的 GET /v1/repos/{repo}/status 现在只有 {root, head, branch, ahead, behind, dirty, locked} —— 没有 remote，也没有 avatar。 所以 DEMO 里的徽标一律是 GitHub mark 图标（内联 SVG）。 等内核补了 remote，客户端可以从 github.com/<owner>.png 拿仓库头像； 09 号就是「有头像时」的样子（占位图，不是真图），位置和尺寸与 01–08 完全一致， 到时候只换 .av 里的内容，布局一行都不用改。

本地路径的 9 种摆法

  • 00 原样：你选的那条，不加路径 —— 只当尺子。
  • 01 三行：路径当第三行（最直白，代价 +14px 高）。
  • 02 路径右贴：路径挤到第一行右侧，高度不变；300px 里只剩 106px 给路径，会省略。
  • 03 路径条：下方独立一段 + COPY，路径和动作配对，最清楚，代价 +20px。
  • 04 折叠：平时只露尾段，悬停展开完整路径 + COPY（两格画了两态）。最省，多一层状态。
  • 05 面包屑：⌂ / opt / Nous-skills 分节，可点某一节复制。好看，但点中哪节会误触。
  • 06 右侧双读数：LOCAL / REMOTE 竖排 9px 读数，像仪器。信息最密，字最小。
  • 07 双徽标：GitHub mark + 右下角「本地盘」小圆标，路径第三行。语义最全（远端 + 本地）。
  • 08 换底路径段：路径段用 #0a0a0a 换底，视觉上「这是另一层信息」。
  • 09 头像位：01 的布局，只把图标换成圆形头像 —— 验「有 avatar 时」不会挤。

我的推荐

03 路径条：上段是 02 原样（头像 + 仓名 + 分支 / 待发布 + 圆按钮），下段是 /opt/Nous-skills + COPY，一条 hairline 隔开。理由：路径是「排查时才要」的信息， 不该挤在两行里跟仓名抢宽度；而 COPY 是它唯一的动作，摆在一起才不用猜。
