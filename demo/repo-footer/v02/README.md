## 头像（先说清楚）

引擎的 `GET /v1/repos/{repo}/status` 现在只有 `{root, head, branch, ahead, behind, dirty, locked}` ——
**没有 remote，也没有 avatar**。所以：

- 徽标现在是 **GitHub mark 图标**（内联 SVG，16px，28px 方框里居中）。
- **09 头像位已砍**：不实现「去 `github.com/<owner>.png` 拉头像」，也就不存在离线回落、
  缓存和隐私问题；那一格只留作记录。
- 等内核补了 `remote`，客户端可以从 `github.com/<owner>.png` 取仓库头像 ——
  **09 号**就是「有头像时」的样子（现在是灰圆占位，不是真图）。布局和 01 完全一样，
  到时候只换 `.av` 里的内容，别的都不用动。
- 头像右下角那颗 5px 白点 = 「有未发布」。没有待发布就不画点。

## 关于 10a–10c（这一轮新加的）

**10a / 10b / 10c 是三个各自真实的页面，不是三条仓片并排。**
（第一版我把三条仓片堆在一条底栏里，那是真实界面里不会出现的形态 —— 底部永远只有当前段那一个仓。）

- **10a 技能页**：6 条技能 + 技能仓。
- **10b 提示词页**：5 条提示词（`smart-ass` 标「默认」= `settings.json` 的 default）+ 提示词仓；
  树栏跟着变成「未分类 5 / 默认 smart-ass」。
- **10c 扩展页**：5 条扩展（核心三条 / 未提交 / 加载失败）+ extend 仓；
  树栏「启用中 5 / 加载失败 1」；分支 `feat/skills-upstream-source`；**没有 ↗** —— 没 remote 就不画。
  这就是「纯 Desk 终态」的真样子。

三段是同一个 `plaque()`，区别只有：仓名、分支、路径、「处」的口径（扩展只数扩展目录）。
整页舞台里点 10a/10b/10c，**树栏、列表、底部仓片三处会一起换**，不是只换底条。
- **11 / 12 / 13 长分支截断**：300px 放不下 `feat/skills-upstream-source`。
  三种截法里我选 **11 中间省略**：既看得出是特性分支（`feat/`），也看得出末尾（`source`），
  完整值放 `title`。12 尾部省略会让两个同前缀的分支长得一样，13 只留前缀则看不出是哪个分支。

## 我的推荐

**03 路径条**：上段保持 02 原样，下段 `/opt/Nous-skills` + `COPY`，一条 14% hairline 隔开。

理由：路径是「排查时才要」的信息，不该挤在两行里跟仓名抢宽度；COPY 是它唯一的动作，
摆在一起才不用猜。300px 宽度下，02 右贴只剩 106px（`/opt/Nous-s…`），06 已经是我能压到的极限
（仓名 96px + 读数 108px + 头像 28 + 按钮 24 + 间距），再压仓名就要省了。

次选 **04 折叠**：极简派的答案，但「路径默认不显示」和你要的「要有本地路径」差半个身位。
