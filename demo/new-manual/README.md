# New Manual 盘面 · 外观 10 方案

只做**外观**，不动 Rust。挑中哪一套，再按那套写 `crates/nousdesk/src/board.rs` / `board_art.rs`。

## 怎么看

```bash
cd demo/new-manual
python3 -m http.server 8000
# 浏览器开 http://localhost:8000/   （顶部 01–10 切换，键盘 1…0 / ← → 也能切）
```

一个页面十套，左栏（图标条 + 会话列表）**十套共用** —— 那是现状，不在这次要改的范围里。
右格才是方案本体。窗口按 1400×860 画，窄屏会等比收窄；右格宽 = 1400 − 56 − 280 = 1064。

数据全部取自现状截图：`volc-ark/deepseek-v4-flash-260425`、`Skills 0/5`、`prompt smart-ass`、
`Extensions none`、`Permissions` 空（内核没做）。

## 十套一句话

| # | 名字 | 这套想干什么 | 主要代价 |
|---|------|--------------|----------|
| 01 | 单色网格 | 把地形图拆成四张表，中央换成一块真正的表单卡；靠 1px 线和对齐分区，一个空间只干一件事 | 丢掉 Cynefin 那张图的「自己在哪」的暗示 |
| 02 | 纸面 | 和左栏同一张纸，右格不再硬切深色；白天用、截图、打印都成立 | 和现有 Flexoki 盘面完全两种气质，改就得整页重画 |
| 03 | 蓝图 | 既然整页是一张参数图，就按工程图纸画：点阵底、虚线分区、角标、X 轴 | 装饰性最强，看久了容易累；也需要更多 canvas 绘制 |
| 04 | 流水线 | 四象限本来就有依赖顺序，摊成一条创建流水线；左边选，右边永远是那一个表单 | 失去「一张图」的整体感，四块变成四步 |
| 05 | 提纯 Cynefin | **骨架和你现在这版一样**（真地形图 + 中央椭圆），只把四块彩色拿掉、中央加玻璃层 | 改动最小，提升也最小；还是深色一页 |
| 06 | Bento | 格子的尺寸就是重要性：Model 最大、Permissions 最小并标 soon；中央 Create 占主位 | 每格内容少时留白显空；不是「图」，是卡片墙 |
| 07 | 轨道 | 中心只有一个动作（Create），四个维度是它的参数，虚线说「谁喂给谁」 | 四块离得远，窄窗里容易互相压；连线要按尺寸重算 |
| 08 | man page | 名字就叫 New Manual —— 照 man page 排版：全等宽、段标题、一行 `$ create` | 最不「微信」也最不「Tesla 官网」，但最有辨识度 |
| 09 | 编辑流 | 字号和留白当层级，不用框线；四个词 40px 站着，白卡压交叉点 | 信息密度最低，一屏装不下更多东西 |
| 10 | 上下分屏 | 上半永远是完整地图（比例不变形），下半永远是可读表单；半屏 / 窄窗里地图不会被压成竖条 | 地图变小了一半；「象限」和「中央」的空间关系弱了 |

## 我的取舍（供反驳）

- **和现有设计语言最不打架的是 05**：同一张图、同一个椭圆，只去彩、加层。想小步走就选它。
- **最像 NousDesk（微信骨架 + Tesla 语言）的是 01 / 06**：黑白灰、字号说话、一个强调动作。
- **最能解决现有毛病的是 10**：现状最大的问题是「窄右栏里四象限 + 椭圆挤成一团」，
  上下分屏直接绕开它，且和半屏窗口的行为一致。
- **08 是唯一自带性格的**：`New Manual` 这名字本身就是 man page 的梗，别浪费。
- 02 是唯一能解决「浅色左栏 + 深色右格硬切」的方案；如果哪天做浅色皮，它可以直接跟上。

## 现状对照

现状截图（Xvfb + 真二进制）：四块 14% 叠色、中央虚线椭圆、表单全是小胶囊、无顶栏。
十套都保留了这个信息架构：四个维度 + 一个「建」的动作 + 名字 / 机器 / 目录 / Create。
