# 弹层太小（980 宽）· 三套解法

**问题**：980 窗口的右格只有 644 宽，点开一项之后那张弹层还按「小卡片」的尺度算 ——
标题 12.5px、提示 10px、正文 13.5px、底栏 `Esc 关闭 · 点空白处也关` 只有 **8.5px**；
而盘面主文案是 19px。进去一下反而更小，1x 屏上就是看不清。

盘面不动（就是线上这版竖轴 D），三套只改「点开之后那一下」：

| | 摆法 | 字号 | 代价 |
|---|---|---|---|
| **A · 撑满右格** | 浮层，左右各 16，宽 612；遮罩 0.20 | 标题 19 / 正文 15.5 / 说明 12.5 | 几乎零成本：改 `pop_rect` 的宽度公式 + 字号档位 |
| **B · 底部上滑 sheet** | 浮层，贴满宽、918 高、只留上圆角、抓手 + 搜索 + 分组 | 标题 22 / 名字 17 / 说明 13.5 | 要加一种 sheet 形态（底锚 + 全宽 + 圆角只上两角）；遮罩 0.34 盖住整个盘面 |
| **C · 整格换页** | 不叠浮层，右格整页换成选择页（`‹ 盘面` 回去） | 标题 19 / 正文 16 / 说明 13 | 要把 sheet 渲染成 pane 内的页面而不是 absolute 浮层；看不见盘面 |

```bash
python3 demo/pop-980/build.py     # → preview.html（243 KB，字体 base64 内嵌）
```

双击 `preview.html` 就开；顶部按钮 / 数字键 1–3 / `#a` `#b` `#c` 切换，右上角滑块是整页缩放（默认 62%）。

**量的是线上这版**：`crates/nousdesk/src/board.rs` 的 `board_sheet`（标题 `m.f(1.3,10,12.5)`、
提示 `m.f(1.05,8,10)`、底栏 `m.f(0.8,6.5,8.5)`）与 `board_art.rs` 的 `pop_rect`
（Model 560 / Skills·Ext 588 / 其余 460，再在 644 里居中）。
