## 页面本体不是示意图

`preview.html` 里的窗口是照着 `crates/nousdesk/src/app.rs` 的结构抄的，不是"大概齐"：

| 部分 | 代码出处 | 实测值 |
| --- | --- | --- |
| 图标条 | `render_icon_bar` | 宽 56，40×40 格，图标 20，`sidebar` 底 |
| 会话列宽 | `Skin::INDUSTRIAL.list_w` | 280 |
| 搜索行 | `render_list` 顶部 | `px12 / pt12 / pb8`，搜索框 28 高 + `＋` 28×28 |
| 会话行 | `session_row` | `min_h 56`、`pl8 pr10 py6`、`border_b 1px 纯黑`、选中 `selected` |
| 目录列 | `nav_ui::nav_column` | 宽 240，`panel_alt` 底 |
| 聊天顶栏 | `render_chat` 头部 | 高 48、`list_bg` 底、分支/收起/历史三颗 28 高 |
| 气泡 | `bubble` | `max_w 480`、内 `px12 py8`、用户右贴 / 助手左贴 |
| 输入区 | `composer::render` | 外层 `8/10/10` + `hover` 底，白卡，写字区 13.5px，发送 26 高 |

尺寸一律按工业皮的 `density = 1.05` 乘过（56 → 58.8、8 → 8.4…），
圆角一律 0（`radius_scale = 0`），分隔线是纯黑 `#14150f`，字体 Manrope + JetBrainsMono，
色值全部取自 `theme.rs` 的 `Palette::INDUSTRIAL`。

会话列表里的名字是真实那批（`对话 371` / `scratch 11-13 19:16` / `真模型` / `j1900 迁移`），
其中只有 1 条有预览、1 条在跑 —— 跟引擎里 149 条主线「142 条没内容」的实况一致。

## 为什么都这么矮

会话列只有 **280 宽**，而这一行夹在搜索框（28）和第一条会话之间。
每多占 10px，列表就少显示 1/6 行 —— 149 条会话时这 10px 是有代价的。
所以最重的方案 7（42）和最轻的 9（24）差 18px，一屏能差 1 条会话。

外面那圈灰底 + 顶部切换条**不属于被审的页面**，是 demo 自己的骨架。
