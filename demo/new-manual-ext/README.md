# 扩展（Extensions）· 卡片 + 弹层

分支 `design/ext-demo`。双击 `index.html`，纯静态。

## 前提：接口已经在了

`GET /v1/extensions` 早就在跑（之前记的「等 vbe4pt 给接口」是过时信息）。返回里有：

| 字段 | 真实值（2026-11-16） |
| --- | --- |
| `installed` / `loadable` | `nous` `skills` `prompts` `123` |
| 核心（`defaults` = `CORE_EXTENSIONS`） | `nous` `skills` `prompts` |
| `builtin` | `coding-tools`（不在仓库里，跟引擎走） |
| `variants` | `123@123`，`load.state = failed` |
| `archived` | `demo`（2026-11-04） |
| `repo` | `drift: true` + `pullError`（分支没跟踪信息） |

写接口也全有：`install` / `uninstall` / `reload` / `archive` / `restore` / `publish` / `create` …

**但 `uninstall` 对核心三条返回 403**（`server.js` 的 `localUninstall`）：
`nous` / `skills` / `prompts` 是引擎启动路径上硬编码 `import` 的，删了下次起不来。

⇒ **这一屏上真正能拨的开关只有 `123` 一个。** 所以这个面板的重心不是「选择器」，
是「我这儿都装了什么、哪些不能动、有没有坏」。

## 七套

| # | 方案 | 说明 |
| --- | --- | --- |
| 00 | 现状 | 卡片只有 `none`，点开没弹层 |
| 01 | 卡片上写什么 | 4 种：`4 装上 · 3 核心` / `4 / 4` / 名字列表 / **圆点** |
| 02 | 弹层 · 一列多选 | 最省事，但分不出内置/归档/变体 |
| **03** | **弹层 · 分组列表（推荐）** | 启用中 / 内置 / 变体 / 已归档，按**状态**分组 |
| 04 | 弹层 · 表格（620） | `sections` 单独成列 —— 扩展真正的价值是塞了哪几段进提示词 |
| 05 | 弹层 · 左树 + 右列表 | 技能同款；但「内置/变体/归档」不是分类，塞不进树 |
| 06 | 弹层 · 双列卡片（620） | 4 条正好 2×2，再多就得滚 |

## 倾向 03 + 卡片第 4 种（圆点）

- **弹层按状态分组，不按类别**：技能是「挑能力」，所以按类别；扩展是「看状态」，
  真实结构是「哪些能用、哪些不能动、哪些坏了」
- **卡片用圆点**：5 个点一眼看出坏了一条，`4/5` 顺带也在；`4 装上 · 3 核心` 要读两个字

## 还有三件要定

1. **能勾的只有一个，还画勾选框吗？** 倾向照画 —— 画面上「为什么这三个点不动」比
   「一个都不画」更能说明架构。但核心那三条必须是锁的样子，不能跟「用户只是没勾」长得一样。
2. **`drift: true` 报不报？** 仓库分支没跟踪信息，`pullError` 一直挂着。倾向**不报在卡上**
   （跟这次会话无关），只在弹层底部放一行灰字。
3. **归档的要不要露？** `demo` 是三个月前的测试扩展。倾向**默认折叠**，点「已归档 1」才展开。
