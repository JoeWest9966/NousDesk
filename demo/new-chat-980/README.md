## 四套

| | 名字 | 一句话 |
|---|---|---|
| **D** | 竖轴清单 | 一条竖轴串四个节点，从上往下就是一次「填参数」；参数区被四种状态平分，脚下一行命名 + 创建 |
| **E** | 终端邀请 | 把「新建」当成敲一条命令：黑卡里七行参数，点哪行改哪行，底部一颗反白 `[ CREATE ]` |
| **F** | 白纸 + Dock | 先把「第一句话」摆在正中，参数全退到脚下一条 dock；参数不再抢戏，想改再点 |
| **G** | 配置单 | 四块大数字压在上面，下面一张两列参数表逐项可点 + 权限开关；信息量最大，一眼扫完再动手 |

四套共同目标：**1134 高不再有一大片「漏了一截」的空白** —— D 用分区平分、E 用终端留白 + 注释行、F 用建议列表、G 用数据块 + 参数表填满。
