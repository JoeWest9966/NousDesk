# 轨道盘面 · 选择页 6 方案

方案 **07 轨道**（你挑的那套）继续往下做：盘面不动，做**点进去之后那一层** ——
模型 / 技能 / 提示词 / 扩展 / 权限 / 机器 / 目录，七种选择页，六种不同形态。

```bash
xdg-open /opt/NousDesk/demo/new-manual-7/index.html
```

顶部 `01`–`06` 切换形态（键盘 `1`…`6` 也行）。切形态时**已经打开的选择页会原地换成新形态**，
方便同一个维度横向比较。

## 点哪里

盘面上六个入口，全部可点：

| 入口 | 打开 |
|------|------|
| Model 卡片 | 模型：供应商 › 模型 › 思考 三列 |
| Context 卡片里的 `SKILLS` | 技能（多选） |
| Context 卡片里的 `PROMPT` | 提示词模板（单选，再点取消） |
| Extensions 卡片 | 扩展（单选，标了「来自 vbe4pt」） |
| Permissions 卡片 | 权限（内核没做，只展示） |
| 底部 `本机 ›` / `— ›` | 机器 / 工作目录（目录是一层层点进去） |

选完回填到盘面卡片上（Skills 会从 `0 / 5` 变），Esc / 点空白处关闭，Create 会弹一行 toast
（`create · model · skills · prompt`，只是演示，不发请求）。

还有一个捷径：`index.html#dir`、`#model`、`#skills`、`#machine` 直接开在那一页。

## 六套一句话

| # | 名字 | 这套想干什么 | 主要代价 |
|---|------|--------------|----------|
| 01 | 浮层卡片 | 遮罩 + 居中面板，最标准；三列铁路图能完整横排 | 最普通，和「轨道」的气质断开一截 |
| 02 | 右侧抽屉 | 从右边滑进来，地图还看得见；长列表不用挤在一屏 | 宽 440 放不下三列，Model 只能竖着堆三段 |
| 03 | 就地弹出 | 贴着被点的节点弹，箭头指回去；注意力不离开盘面 | 模型页要 560 宽，会盖住旁边的 Context 卡 |
| 04 | 全屏接管 | 整块右格切成选择页，左上角返回；行最大、字最大 | 地图整个消失，失去「盘面」的存在感 |
| 05 | 旋钮 | 每列 5 行窗口，选中项永远停在中间一行，最像「拧一下」 | 一次只能看几行；技能这类集合看不出总量 |
| 06 | 命令面板 | 输入即过滤，像 ⌘K；维度越多越省事 | 「看着选」不如列表直观，模型的三段依赖被压成一行 |

## 我的取舍（供反驳）

- **兜底选 01**：三列铁路图是这一页的灵魂，只有浮层和全屏给得起宽度。01 的代价只是「不惊艳」。
- **想保留盘面就选 03**：弹出贴着卡片，背景只压暗不打糊，很轻。
- **最像 Tesla 的是 04**：车机设置就是整屏接管 + 左上返回。代价是地图要让位。
- **05 只适合 Model**：供应商 / 模型 / 思考本来就是三档旋钮，拧起来很顺；技能用它反而别扭。
- **06 适合技能和模板**（5 条起、要搜），模型也能用，但把「供应商 › 模型」的依赖压成了一行字符串。
