插件页：把「依赖层」也列出来

引擎里其实有 两份东西：端点模块（自带 HTTP 端点、客户端能调用）和依赖层（被依赖的库，零端点）。

现在 Desk 插件页只列了前者，所以 ai / durable / wire / routes 你在列表里找不到 —— 但关系图里明明有它们，点胶囊跳过去是一片空白。

–有 plugin.toml 的插件
–端点模块（现在能看见）
–依赖层（现在看不见）
点左边任意一行看右边；改前模式下点带 ? 的胶囊，看它为什么是空的。

这张票要做的（A + C，零引擎改动）

  1. 插件页左侧列表分两段：端点模块 · 15 和 依赖层 · 16，数据都从已有的 GET /v1/modules/graph 来（31 个节点 / 96 条边，已经在发）。
  2. 依赖层的行：名字 + vendor + 版本 + 层 + 被 N 处依赖，端点一栏留空（不是 0 端点）。
  3. 点依赖层任意一行 → 详情页显示 来源 crate / 层 / 版本 / 依赖 / 被依赖，顶部一句「这是库，不提供端点」。
  4. 关系胶囊现在点了会跳到一个不存在的模块 —— 改成跳进这个新详情（闭环）。
  5. 不影响 capabilities：modules[] 仍是 15 个，端点仍是 165 条，不往契约里塞空端点行。
