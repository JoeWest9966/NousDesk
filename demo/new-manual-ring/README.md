# New Manual · 05 环 · 五套皮

你选的 **05 环**，配 `main` 上真实存在的那五套皮（不是我上次那份十套老皮）。

```bash
xdg-open /opt/NousDesk/demo/new-manual-ring/index.html
```

顶部切皮（键盘 `Q W E R T`），第二行切状态（`1` 就绪 / `2` 提交中 / `3` 未选模型）。

## 这套在做什么

中央那颗圆是**唯一**的动作。圆外一圈虚线环，名字 / 机器 / 目录三个值**挂在环上**
（pill 盖住环线，像珠串），圆边再各引一条短线过去 —— 这三样是「从圆心长出来的参数」，
不是底下一条独立的横条。四张卡在外面，各用一条虚线连到圆心。

**三个 pill 的底色和中央圆完全一样**（`fg` 当底、`bg` 当字）：浅皮里是黑圆 + 黑珠，
单色皮里是白圆 + 白珠，琥珀皮里是米白圆 + 米白珠。它们不是另外三个控件，
是从圆心甩出去的三颗珠子 —— 换皮时一起换，颜色不许自己另长一套。

以前那版的问题：底部一条 720px 宽的 dock，横贯整个盘面，看起来像「工具栏」，
和上面四张卡不是一个语法。环把它们收回到圆边上，语法统一成「节点 + 虚线」。

## 五套皮（色值照抄 `crates/nousdesk/src/theme.rs`）

| 键 | 皮 | 这套底下长什么样 |
|---|---|---|
| Q | 默认 | 浅灰底 `#ededed` + **黑圆白字** + 微信绿虚线环；圆角 1.0 |
| W | 工业 · 纸与黑线 | 暖白 `#f4f2ee` + **纯黑线**（`line` 就是 `#14150f`）+ **直角**（`radius_scale 0`），Manrope |
| E | 单色 · 纯黑白 | 纯黑底 + 白线 + **白圆黑字**；直角，没有第二个人颜色 |
| R | 纸 · 暖白 | 暖白 `#fbfbfa` + 灰线，微圆角 0.75，最轻 |
| T | 琥珀 · 暖黑 | 暖黑 `#0d0c0a` + 米白圆 + **琥珀虚线环** `#e8a33d`；圆角 0.375 |

两个跟皮走的关键决定：

1. **圆用 `fg` 当底、`bg` 当字** —— 所以深色皮是浅圆深字，浅色皮是黑圆白字，
   五套都稳。要是把圆钉成「白色」，单色和琥珀皮上会白得发糊。
2. **环用皮的强调色**（默认绿 / 工业黑 / 单色白 / 纸灰 / 琥珀琥珀），不用固定色。
   环是这页的主角，它得跟着皮说话。

直角皮（工业、单色）会把 pill 也变成方角 —— 那是 `radius_scale` 的活，不是这一页的活。

## 三个状态

- **就绪**：圆是实底，环正常，三个值可点。
- **提交中**：圆换 `Creating…`、压到 75%。
- **未选模型**：圆变浅底 + 描边、字变淡，三个值一起压到 40% —— 一眼看出「还差一个模型」。

## 落地映射

`board.rs` 里把 `board_dock()` 换成 `board_feet()`，三样东西的数据源不变：

| 值 | 现在 | 之后 |
|---|---|---|
| 名字 | `Textarea`（dock 里） | 同一个 `TextareaState`，装进环上中间那个 pill |
| 机器 | `Option<String>` | 不变，左右 pill 之一 |
| 目录 | `Option<String>` | 不变，左右 pill 之一 |

坐标全部进 `board_art.rs`（和 `node_rect` / `pop_rect` 一个文件）：

- 圆：`core_center` / `core_r`（不变）
- 环：`ring(cx, cy, rx, ry)`，rx / ry 由 `M` 算
- 三个值的落点：环上的角度参数（左 135°、中 90°、右 45°），别在渲染里写死百分比

连线仍然走 `board_wires()`：环是一个 `<path>`/`ellipse` 的 `dash_array([2,6])`，
圆到三个值的短线是三条 `M..L..`。

**主题**：现在 `board_art.rs` 是写死深色的一套常量。要让盘面跟皮走，
那些常量得改成从 `Skin` 取（`chat_bg` / `panel` / `line` / `text` / `accent`），
和 `theme.rs` 里其他页一个来源。

数据都是假的，只为看形态。
