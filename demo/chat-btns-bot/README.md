# demo · 纯图标那一行，机器人风（6 套）

**只看这个文件**：`/opt/NousDesk-chat-btns/demo/chat-btns-bot/preview.html`
单文件、字体 base64 内嵌、双击就开。顶上 `1 … 6` 切换，点按钮只切高亮，**不做功能**。

## 和上一版的关系

上一版 `demo/chat-search-btns/` 的第 2 套「纯图标」定了框架：
30×30 方块、选中反白、右端挂 `149 条`、不写字。**这一版只换图标语言，框架不动** ——
所以六套能被直接横向比，变量只有"图标长什么样"。

页面本体（rail 56 / 会话列 280 / 目录列 240 / 48 高聊天顶栏 / 气泡 / composer）跟上一版
逐值相同，都来自 `app.rs` + `theme.rs` 的 `Palette::INDUSTRIAL`（density 1.05、radius 0、
线色纯黑）。改动只在按钮行。

## 尺寸纪律（踩过才知道）

第一版图标是 18px、线宽 1.6 —— 渲出来线只有 **1.2px**，机器人头的眼、耳、嘴全糊成灰块，
千斤顶缩成一团"塔"。所以定死三条：

- 按钮 **30×30**（键帽 34），图标 **20px**（脸 / 表盘 22px）
- 线宽一律 **2.0**（20px 下约 1.67px，和 rail 24px / 1.7 一样清楚）
- **不留只有 1px 的零件**：头的侧耳、嘴线、天线球全砍了；小尺寸下会消失的东西不如不画

## 第 1 套的定稿说明（2026-11-25）

前两颗换成模板页分段按钮上的**芯片图标**，源码直接从 `crates/nousdesk/src/template_icons.rs`
搬，不是重画的：

| 位置 | 常量 | 长什么样 |
| --- | --- | --- |
| 第 1 颗 | `SESSION` | 芯片 + 左右各 3 根引脚 + 芯里一个实心**播放三角** |
| 第 2 颗 | `ULTIMATE` | 芯片 + **四面**各 3 根引脚 + 中心实心**圆核** |

照抄的地方：24 viewBox、`stroke-width 1.6`、`linecap/linejoin: round`、芯片 `rx 1.4`。
**尺寸也照抄 24px** —— 这两枚是"图标当家"的画法，引脚间距只有 1.9 个单位，缩到 20px
会糊成一团（之前踩过）。后两颗机甲图标同样放到 24px，线宽降到 1.8 陪它。

之前一版理解错了，把两个段切换药丸（文字块）当成图标摆进去 —— 已经删掉。
