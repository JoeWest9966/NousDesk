## 三件难看的事，八个方案就是在回答它们

1. **层级**：`工程/事故` 是两级。拍平会丢，缩进会占宽。
2. **多类**：`deep-dive` 同时在 `写作` 和 `写作/长文`。分组时重复出现还是只出现一次？
3. **空类 / 无类**：`实验`、`Basics` 是 0 条；`scratch-notes` 不属于任何类。

## 倾向 04

`03` 已经把「类别是信息」说到位了，但技能长到十几条时一定要收窄，那时 03 得重做；
`04` 的 chip 正好在「现在用不上、以后接得住」。

`02` / `08` 要 620 以上宽度，和目录弹层同一量级 —— 技能弹层现在只有 460，
跳档要单独论证。`06` 的多选等技能超过 ~15 条再说。

## 落地前要定的一条

`incident-postmortem` 属于 `工程`，也属于子类 `工程/事故`。分组时：

- **只出现在 `工程` 段**，行尾标 `事故`（demo 里 04 画的这个）—— 不重复
- 或者 `工程` 和 `事故` 两段都出现 —— 好找，但同一行出现两次

倾向只出现一次。定了写进 `decisions.md`。
