# demo · 资源页（02 落地稿）

`demo/resource-pages` 那五套里挑中的是 **02**：左栏一个「资源」图标，页内三段
（技能 / 提示词 / 扩展），骨架照 Template 页 —— 类别树 248 + 列表 300 + 详情。

这一份不再比方案，**只把每一屏画细**：三页主界面、三个新建、发布、编辑、空态。外观稿，不进构建。

## 怎么看

```
/opt/NousDesk-respages/demo/resource-page/preview.html
```

单文件，双击就开。左边 **01–09** 是九个镜头（`#skills` … `#states` 也能直接跳），
下面两排开关：

- **段 A / B / C** —— 段按钮的三种形态（**已定 B**，A/C 留作对照）：
  A 药丸（名字 + 条数）· **B 药丸 + 脏点** · C 图标 + 名字 + 条数。
  默认打开就是 B。
- **皮 默认 / 琥珀** —— 三个新页在暗色底下也得成立。

**能点的**：三段切换、类别筛选、行选中、搜名字、`新建`（三张不同的表）、
树脚「N 处待发布」（三个仓的发布层）、详情头「编辑」（整页工作台）、
空态卡片里的按钮、`≡` 菜单、Esc 逐层退。

## 九个镜头在说什么

| | 镜头 | 一句话 |
|---|---|---|
| 01 | 技能 · 主界面 | 类别在上、**状态在下**（变体 / 藏起来）；行里那句摘要会进模型的技能清单，不是装饰 |
| 02 | 提示词 · 主界面 | 单值 → 列表是单选形状；「引擎默认那条」单独成组，因为默认 ≠ 我选的 |
| 03 | 扩展 · 主界面 | 状态在上、类别在下；五类状态各自可点；详情里有一行 `sections` 的**对账** |
| 04 | 新建 · 技能 | 名字 = 目录名 = 会话键，**建完不能改**；description 必填（引擎 400 的原话） |
| 05 | 新建 · 提示词 | 摘要必填（人靠它挑），正文可空；**建完该直接进编辑器** |
| 06 | 新建 · 扩展 | 骨架**故意什么都不装**（`sections: []`）—— 新扩展默默往提示词塞一段是最难查的惊喜 |
| 07 | 发布 · 三个仓 | 三份闸、三个 remote，**没有「一键全发」**；扩展还分 `sync` / `publish` 两条路 |
| 08 | 编辑 · 正文 | 面包屑回得去；右边永远写着「保存 ≠ 发布」；第一关是内容闸 |
| 09 | 空态 · 坏态 | 四种空/坏各有一条出路；没有一格是「请稍后重试」了事 |

## 这一份的主张（等确认）

1. **段按钮定 B（带脏点）**。三个仓的脏状态分开显示、不合并成一个总数 ——
   一个琥珀点 = 有未提交的改动，红点 = 有条目加载失败。C 那套图标在 248px 里挤，
   而且图标本身不承载信息（三个都是「一类东西」，看不出谁脏）；A 少了状态，
   「有个坏的」永远发现不了。**这一条已拍板，默认就是 B。**
2. **新建三张表各说各的必填项**，表单里**当场预览落盘内容**（`SKILL.md` / `PROMPT.md` /
   `index.js` 骨架 + `nous.json`）。名字规则和引擎一致：`^[a-z0-9][a-z0-9._-]*$`、≤ 64 字符；
   扩展不能撞核心三条（`nous` / `skills` / `prompts`），说明 ≤ 200 字。
3. **建完停在「未发布」并选中新条目**（提示词直接进编辑器）。不自动发布 ——
   发布是一个要过闸的动作，不该藏在新建按钮后面。
4. **发布是三个仓各走各的**。合并成一次 commit 之后，「技能闸过了、扩展闸没过」
   就说不清该退哪一半。
5. **编辑是整页，不是右栏抽屉**：`SKILL.md` / `PROMPT.md` 要的是宽，右栏那 400px 里
   一行代码都放不下（Template 页的 `editor.rs` 已经是这套）。

## 改 demo

```bash
cd demo/resource-page
# base.html    = 上一份 demo 里 02 那一套（只是素材，别改）
# build.py     = 把 base.html 的样式/图标/渲染函数和这份的新正文拼成 index.html
# index.html   = 生成物（能直接开）
# data.js      = 真数据
python3 build.py            # base.html + 新正文 → index.html
python3 build-preview.py    # 字体 + data.js 内嵌 → preview.html
```

## 落地顺序（Rust）

1. `Tab` 加一项 + 图标条加一颗（`app.rs`）；页内三段用 `Tab` 内部状态
   （照 `templates.rs` 的 `section` 那套）。
2. `nous-engine` 补三个仓的写接口：`skills` / `prompts` 一套（files / file PUT / create /
   publish / archive / restore / purge / sync / pending），`extensions` 一套
   （files / file PUT / create / publish / sync / install / uninstall / archive / restore / purge）。
3. 骨架抄 `templates.rs`（`facet_tree` / `cat_row` / `repo_line`），正文编辑复用 `editor.rs`。
4. 三个新建表按镜头 04–06 落地；校验文案直接用引擎的原话（别翻译成「请检查输入」）。
5. 落地后截图对照镜头 01–09，不一致算没做完。
